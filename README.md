1. Цель работы
Целью лабораторной работы являлась разработка мини-веб-приложения, реализующего:
собственный HTTP-сервер на базе HTTPServer и BaseHTTPRequestHandler;
работу с несколькими моделями данных (пользователи, валюты, автор, приложение);
использование шаблонизатора Jinja2 для формирования HTML-страниц;
интеграцию с внешним API курсов валют (ЦБ РФ);
обработку маршрутов /, /currencies, /author, /user;
проведение модульного тестирования моделей, контроллера и функции получения валют.

2. Описание предметной области
В рамках приложения реализованы следующие модели:
Модель user
Содержит:
id — строковый идентификатор пользователя (минимум 6 символов);
name — имя пользователя (минимум 2 символа).
Имеет валидацию в сеттерах.
Модель user_currency
Описывает пользователя и список валют, на которые он подписан.
Модель currency
Описывает валюту и её текущий курс.
Модель author
Хранит имя автора и номер группы.
Модель app
Хранит название и версию веб-приложения.
Связи:
user_currency содержит ссылку на модель пользователя.

Валюты загружаются из внешнего API функцией get_currencies.

4. Описание реализации

4.1. Реализация моделей
Модели реализованы в отдельных файлах в папке models.
Каждая модель имеет:
конструктор с базовыми свойствами,
сеттеры с валидацией,
геттеры, обеспечивающие доступ к данным.

4.2 Реализация маршрутов и обработка запросов
Основная логика находится в файле myapp.py.
Для создания веб-приложения используется стандартная библиотека:
from http.server import HTTPServer, BaseHTTPRequestHandler
Маршруты реализованы в методе do_GET класса MyHandler:
/ — главная страница приложения.
/currencies — отображает список валют.
/author — информация об авторе.
/user?id=... — детали конкретного пользователя.
POST-маршрут /action обрабатывает подписку на валюту.

4.4. Интеграция get_currencies
В файле utils/currencies_api.py реализована функция:
def get_currencies(currency_codes: list) -> dict:
Она:
делает запрос к API ЦБ РФ
преобразует data["Valute"] в удобный словарь
возвращает курсы только для переданных валют.
Функция вызывается в myapp.py при старте приложения для получения актуальных курсов.
